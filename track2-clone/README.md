## 구현 내용

- 시맨틱 태그: `header`, `nav`, `main`, `section`, `article`, `footer`
- 드롭다운 내비게이션 (aria-expanded 접근성)
- CSS Grid: 상품 그리드(4열), 카테고리 타일(4열), 푸터 링크(4열)
- Flexbox: 헤더, 섹션 헤더, 뉴스레터 폼
- 반응형: 1024px(3열), 768px(2열+모바일 메뉴), 480px(단일 열)
